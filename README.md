# Sarvam AI Skill

A skill for AI coding agents (Claude Code, Windsurf, Cursor, etc.) providing expert guidance on [Sarvam AI](https://sarvam.ai) — India's multilingual AI platform for Indian languages.

## What it does

- **Text-to-Speech (TTS)** — Bulbul v3 with 39+ Indian language voices
- **Speech-to-Text (STT)** — Saaras v3 for 23 languages (22 Indic + English)
- **Translation** — Mayura v1 and Sarvam Translate across all Indian languages
- **Chat Completions** — Sarvam-105B and Sarvam-30B LLMs (currently free)
- **Voice Agents** — Real-time pipelines with LiveKit and Pipecat
- **Transliteration & Language Detection**

## Install

```bash
npx skills add abhishek207/sarvam-skill -g --agent '*'
```

## Usage

Triggers automatically when you mention: `sarvam`, `bulbul`, `saarika`, `saaras`, `mayura`, `Indian language AI`, `Hindi TTS`, `Indian voice agent`, `multilingual voice`, `Indic language`, `sarvamai`
